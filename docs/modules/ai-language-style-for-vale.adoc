= AI-assisted prose style for Vale

The optional `AILanguage` style identifies linguistic and structural patterns that commonly occur in AI-assisted prose.
Use it with the `RedHat` style to review technical documentation for formulaic, rhetorical, vague, or repetitive writing.

The `AILanguage` style does not determine whether text was generated by AI.
Each alert identifies a writing pattern that a writer must review in context.
The rules use the `warning` alert level.

.AILanguage rules
[cols="1,2"]
|===
|Rule |Pattern

|`ExplanatoryFiller`
|Explanatory phrases that restate a point, such as _in other words_ or _simply put_

|`NegativeParallel`
|Contrastive framing, such as _not just X, but Y_

|`ParticipialTail`
|Hollow significance clauses, such as _, highlighting..._

|`RhetoricalFraming`
|Rhetorical introductions that delay a technical fact or behavior

|`SummaryBeat`
|Formulaic concluding statements that repeat earlier information

|`ThroatClearing`
|Introductory phrases that delay the technical point

|`VagueAttribution`
|Claims attributed to unnamed sources
|===

The style does not check general vocabulary, punctuation, capitalization, sentence length, emoji, or typography.
The `RedHat` style provides the applicable general documentation rules.

To use the `AILanguage` style:

. Add `AILanguage` to the `Packages` and `BasedOnStyles` fields in your project `.vale.ini` file:
+
.Example .vale.ini
[source,ini]
----
StylesPath = .vale/styles

MinAlertLevel = suggestion

Packages = RedHat, AILanguage

[[!.]*.adoc]
BasedOnStyles = RedHat, AILanguage
----

. Sync the configured packages:
+
[source,terminal]
----
$ vale sync
----

The xref:contributor-guide.adoc#vale-at-red-hat-repository[Vale at Red Hat repository] contains the `AILanguage` style in the following directory:

----
.vale/styles/AILanguage
----
