= AI-assisted prose style for Vale

The optional `AILanguage` style identifies linguistic and structural patterns that commonly occur in AI-assisted prose.
Use it with the `RedHat` style to review technical documentation for formulaic, rhetorical, vague, or repetitive writing.

The `AILanguage` style does not determine whether text was generated by AI.
Each alert identifies a writing pattern that a writer must review in context.
The rules use the `warning` or `suggestion` alert level.

.AILanguage rules
[cols="1,2"]
|===
|Rule |Pattern

|`ContractionScarcity`
|Documents that do not contain contractions

|`ExplanatoryFiller`
|Explanatory transitions that restate a point without adding technical detail

|`Narrative`
|Prescriptive asides that tell readers how to interpret a technical fact

|`NegativeParallel`
|Contrastive framing, such as _not just X, but Y_

|`ParticipialTail`
|Hollow significance clauses, such as _, highlighting..._

|`RhetoricalFraming`
|Rhetorical introductions that delay a technical fact or behavior

|`SummaryBeat`
|Formulaic concluding statements that repeat earlier information

|`ThroatClearing`
|Introductory phrases that delay the technical point

|`VagueAttribution`
|Claims attributed to unnamed sources
|===

The style does not check general vocabulary, punctuation, capitalization, sentence length, emoji, or typography.
The `RedHat` style provides the applicable general documentation rules.

== Rule acceptance criteria

Include a rule in the `AILanguage` style only when it:

. Identifies a documented linguistic or structural pattern.
. Reports a specific writing problem and an actionable revision.
. Has an invalid fixture at each expected alert location.
. Has valid Red Hat technical examples that remain clean.
. Does not duplicate an existing `RedHat` rule.
. Does not routinely overlap another `AILanguage` rule.

The corpus in the `.vale/fixtures/AILanguage/corpus` directory represents ordinary concept, procedure, reference, and general technical content.
All rules except `ContractionScarcity` must produce no alerts for that corpus.
The corpus disables `ContractionScarcity` because Red Hat product documentation prohibits contractions.

[IMPORTANT]
====
`AILanguage.ContractionScarcity` encourages contractions and conflicts with `RedHat.Contractions`, which prohibits contractions in Red Hat product documentation.
Disable `AILanguage.ContractionScarcity` when you use the `AILanguage` and `RedHat` styles together.
====

To use the `AILanguage` style:

. Add `AILanguage` to the `Packages` and `BasedOnStyles` fields in your project `.vale.ini` file:
+
.Example .vale.ini
[source,ini]
----
StylesPath = .vale/styles

MinAlertLevel = suggestion

Packages = RedHat, AILanguage

[[!.]*.adoc]
BasedOnStyles = RedHat, AILanguage
----
+
When both styles are active, add `AILanguage.ContractionScarcity = NO` to the same file type section.

. Sync the configured packages:
+
[source,terminal]
----
$ vale sync
----

The xref:contributor-guide.adoc#vale-at-red-hat-repository[Vale at Red Hat repository] contains the `AILanguage` style in the following directory:

----
.vale/styles/AILanguage
----
