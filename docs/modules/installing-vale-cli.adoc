= Installing Vale

Install the Vale linter to begin reviewing content for style and structure.

[IMPORTANT]
====
If you are working in an established project that has already implemented Vale, you do not need to create a new `vale.ini`.
The project will already have a `vale.ini` configuration.
====

.Prerequisites

* Install the link:https://docs.asciidoctor.org/asciidoctor/latest/install/[Asciidoctor] Ruby gem.

* Install the link:https://cli.github.com/[GitHub CLI].

* If you have previously installed Vale, you can check what version you are currently running.
Run the following command:
+
[source,terminal]
----
$ vale --version
----
+
.Example output
[source,terminal]
----
vale version 3.6.1
----

.Procedure

[NOTE]
====
The `mczernek/vale` Copr repository provides Vale 3.26.0 as its final build.
The repository does not provide Vale 3.27.0 or later releases and does not provide a build for RHEL 10.
====

. If Vale was installed from the `mczernek/vale` Copr repository, remove the old package and disable the repository by running the following commands:
+
[source,terminal]
----
$ sudo dnf remove vale
$ sudo dnf copr disable mczernek/vale
----

. Install the latest Vale release on a 64-bit Linux system by running the following commands:
+
[source,terminal]
----
#!/bin/bash
set -e

cd "${HOME}/Downloads"

gh release download --repo 'errata-ai/vale' --pattern '*Linux_64-bit.tar.gz'

tar -xvzf *Linux_64-bit.tar.gz
sudo install -m 0755 vale /usr/local/bin/vale

# Remove files but not directories
rm -f README.md LICENSE
rm -rf vale-styles
rm -f *Linux_64-bit.tar.gz

echo "Installed $(vale --version) to /usr/local/bin/vale"
----

. To install Vale on another operating system, follow the link:https://vale.sh/docs/vale-cli/installation/[official installation instructions].

. Verify the Vale install location.
You might need to update your text editor with this value.
+
[source,terminal]
----
$ which vale
----
+
.Example output
[source,terminal]
----
/usr/local/bin/vale
----
+
[NOTE]
====
For other operating systems, see link:https://vale.sh/docs/vale-cli/installation/[Installing Vale].
====
